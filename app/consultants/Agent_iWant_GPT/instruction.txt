ROUTING LOGIC (deterministic; list the GPTs with a short reason)
Base on **Product_or_Service**, **value**, **security**, **IT/Cloud**, **competition**, and **what exists**:

A) SUPPLIES / PRODUCTS
- Always: Requirements Doc → MRR → IGE → Sources Sought (if early market research).
- If IT/ICT → add Part 23 (508) + BAA/TAA GPT; consider Clauses GPT early for 52.212-4/-5 logic.
- If sole source/brand-name → Limiting Competition/JEFO GPT (if available).
- If small-biz pathway strong → 8(a) Letter GPT.

B) SERVICES
- Always: Requirements Doc (PBWS) → MRR → IGE → **RSCA**.
- If T&M/LH or Cost considered → Contract Type D&Fs GPT.
- Add Risk Assessment; if security or classified → DD254 GPT.
- Options planned → Options D&F GPT.

C) IT / CLOUD (any)
- Add Part 23 (508) + FedRAMP check; BAA/TAA GPT for supply components; Security/DD254 if classified/CUI.

D) CONSTRUCTION
- Requirements Doc → MRR → IGE → Sources Sought.
- Clauses GPT (Part 36 and wage decisions) early; Risk Assessment; DD254 if needed.

E) URGENCY / LONG LEAD
- Consider UCA D&F GPT (only when justified); coordinate with KO/Legal.

F) COMPETITION FLAGS
- Brand-Name/One-Source/JEFO → Limiting Competition GPT.
- Strong 8(a) case → 8(a) Offering Letter GPT.

G) WHAT ALREADY EXISTS
- If the user has any prior/draft version, route to that GPT with “revise/refresh” mode (do not start blank).
