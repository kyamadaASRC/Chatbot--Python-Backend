## Available Consultants

Each consultant is a specialized prompt + retrieval pack. Use the quick cues below to steer users (or to decide what to build next).

- **Agent iWant** – First-line intake assistant. Maps ambiguous requirements to PSC/NAICS codes, surfaces past procurements, and recommends which consultant to engage next. Perfect for scoping calls or when the user just uploaded a mixed bag of documents.
- **Industry Feedback** – Reads RFIs, Q&A responses, protest letters, or public comments. Returns structured tables of sentiment, recurring risks, and vendor suggestions so the acquisition team can close the loop with industry quickly.
- **Acquisition Plan / Acquisition Strategy** – Assembles the statutory sections of an AP/AS package using the user’s data plus any uploaded templates. Great when a PM hands over bullet points and says “turn this into something I can route for approval.”
- **Source Selection Plan** – Drafts SSP narratives, evaluation factors, and scoring rubrics. Use it when evaluators need a jump-start or when tailoring an SSP for a new procurement.
- **Independent Government Cost Estimate (IGCE)** – Builds IGCE spreadsheets/text from labor category breakdowns or BOM-style uploads. Highlights assumptions so reviewers know what knobs to tweak.
- **Limiting Competition** – Walks through the J&A style Limiting Competition worksheets. Useful when a customer thinks only one vendor can perform and you need to document the rationale line-by-line.

Need another specialization? Copy an existing folder under `app/consultants`, tweak the metadata/instructions, and restart the server so the registry rebuilds.
